How it works

Reading answers feels productive, but saying them out loud is what gets you through the interview.

  1. 1

    Answer out loud

    Read the question and explain your answer as if the interviewer were in front of you.

  2. 2

    Check yourself

    Reveal the model answer and compare. Answers are short, with code where it helps.

  3. 3

    Tick it off

    Mark the question as done once you can explain it with confidence. Progress bars show what's left.

  4. 4

    Star and review

    Not there yet? Star it and come back from your Starred list before the interview.

Frequently asked questions

Is Frontend Interview Prep free?

Yes. Every question, answer and coding challenge is free, with no sign-up, no ads and no tracking.

Do I need an account?

No. Your ticks, stars and code drafts are saved in your own browser, so nothing leaves your device.

What level are the questions for?

Mid- to senior-level frontend roles, roughly 2 to 4 years of experience. Each track starts with fundamentals and moves on to the follow-up questions interviewers ask experienced candidates.

Which topics are covered?

JavaScript (theory and coding), TypeScript, React (theory and machine coding), Next.js, and frontend system design with behavioural questions. HTML and CSS is coming soon.

Can I practise coding questions?

Yes. JavaScript coding questions have an editor with Run and Check buttons that test your solution, and React machine coding questions render a live preview.

Can I suggest a question?

Please do. Open an issue on GitHub with the question, and an answer if you have one.
